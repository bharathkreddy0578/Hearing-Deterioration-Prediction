Project Overview

This project predicts early signs of hearing deterioration by testing a user's current hearing capacity and comparing it against standard, research-based hearing data.

Methodology

Calibration: Device-specific volume-to-dB mapping using microphone feedback.

Hearing Test: Pure-tone audiometry at 500Hz, 1000Hz, and 4000Hz (low, mid, high frequencies).

Comparison: User thresholds compared against ISO 7029, NHANES, and KNHANES normative data.

Prediction: Risk classification based on threshold gaps and trend analysis over time.

Technology Stack

HTML5, CSS3, JavaScript (Web Audio API), JSON

Disclaimer

This project is for academic and educational purposes only. It is not intended as a medical diagnostic tool. Always consult a qualified audiologist for clinical hearing assessment.
